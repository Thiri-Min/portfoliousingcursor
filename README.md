# Thiri Min — Portfolio

A modern, responsive portfolio built with **HTML5**, **CSS3**, **Bootstrap 5**, and **vanilla JavaScript**.

## Features

- Dark glassmorphism theme with gradient accents
- Round profile photo in the navbar (top-left)
- Sections: Hero, About, Skills, Education, Experience, Projects, Training Activities, Contact
- Footer with LinkedIn, YouTube, GitHub, and TikTok links
- Scroll animations, active nav highlighting, mobile-friendly layout
- Training **View Detail** modals with **View Photos** slideshow (no LinkedIn account required)

## Quick Start

1. Open `index.html` in your browser, or use a local server:

   ```bash
   npx serve .
   ```

2. **Profile photo:** Replace `assets/profile.jpg` with your own photo (recommended: square, at least 400×400px).

3. **Resume:** CV is included as `assets/Thiri_Min.pdf` (from [Thiri Min.pdf](https://github.com/Thiri-Min/Portfolio/blob/main/Thiri%20Min.pdf) on your GitHub portfolio repo). Replace this file when you update your CV.

4. **Email:** Update the email in the Contact section (`index.html`) to your real address.

## Deploy to GitHub Pages

1. Create a repo (e.g. `Portfolio`) on [GitHub](https://github.com/Thiri-Min/).
2. Push this folder to the repo.
3. Go to **Settings → Pages** → Source: `main` branch, folder `/ (root)`.
4. Your site will be live at `https://thiri-min.github.io/Portfolio/`.
